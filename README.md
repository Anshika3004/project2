# 🌿 Nature - Wikipedia Style Webpage

A responsive HTML/CSS Wikipedia-style webpage designed to showcase information about **Nature**. This simple static site mimics the look and layout of a Wikipedia article with a top navigation bar, sidebars, content sections, and an image with a caption.

---

## 🧩 Features

- Wikipedia-inspired layout
- Responsive top bar with logo and search input
- Scrollable left sidebar with linked content sections
- Right sidebar for appearance options
- Main content area with headings, images, and paragraphs
- Floating image with styled border and caption
- Pure HTML and CSS — no external dependencies

 🚀 How to Run

1. Clone the repository or download the HTML file.
2. Open the `pro.html` file in your browser.

```bash
git clone https://github.com/yourusername/nature-wikipedia-style.git
cd nature-wikipedia-style
start pro.html
